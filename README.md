# 다시만나 AI

`다시만나 AI`는 실종 반려동물의 여러 기준 사진과 시민 목격 제보를 비교해, 보호자와 구조 담당자가 **어떤 제보부터 확인할지** 결정하도록 돕는 한국코드페어 중등부 교육용 AI/SW 프로젝트입니다.

AI는 실종 동물을 확정하지 않습니다. 검토 우선도는 동일 동물일 확률이 아니며, 사진이 흐리거나 가려졌다면 `판단 보류`하고 추가 자료를 요청합니다.

## 현재 구현

- 반려동물 기준 사진 1~5장과 종류·털 색·얼굴 무늬·귀·체형·꼬리 등록
- 모든 반려동물 특징 항목에서 미리 정한 선택지 또는 자유로운 직접 입력 지원
- 목격 사진·시각·선택 위치·가시성·관찰 특징 0~8건 등록
- HSV 색 분포, 윤곽 방향, 저해상도 시각 패턴 비교
- 선명도·밝기·대비와 분석 신뢰도 표시
- 사진과 관찰 특징을 합친 단서 유사도를 퍼센트와 제보별 막대그래프로 표시
- 일치·불일치·확인 불가 근거를 표로 제공
- `우선 확인`, `추가 확인`, `판단 보류`, `이동 경로 재확인`, `우선순위 낮음` 분류
- 흐림·가림·특징 부족 시 더 가까운 사진과 다른 각도 요청
- 촬영 시각과 대략 거리 또는 선택 좌표로 필요한 이동 속도 계산
- 보호자가 확인한 제보만 시간 순 경로에 사용
- 좌표 없이도 장소 이름·대략 거리·방향을 이용한 시간순 경로와 수색 참고 반경 제공
- 좌표를 선택 입력한 경우에만 지도와 직선 기반 참고 중심 추가
- 실제 개인정보가 없는 가상 데모
- 네트워크·외부 API·모델 다운로드 없는 CPU 실행

## Windows에서 실행

Python 3.11 설치 후 저장소 폴더에서 PowerShell을 열어 실행합니다.

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
pytest -q
streamlit run app.py
```

설치가 끝난 뒤에는 `run_starter_windows.bat`를 더블클릭해도 됩니다.

## 데모 사용법

1. 사이드바의 `가상 데모 자료 사용`을 켭니다. 기본값은 직접 사진 업로드 모드입니다.
2. 기준 사진과 네 건의 가상 제보를 확인합니다.
3. `제보 비교 및 경로 분석`을 누릅니다.
4. 닮은 제보, 흐린 제보, 이동하기 어려운 제보, 특징이 다른 제보의 근거를 비교합니다.
5. 원본을 확인했다고 가정한 제보만 체크해 경로와 수색 범위를 봅니다.

데모 이미지는 OpenCV 도형으로 만든 가상 강아지이며, 위치도 실제 구조 활동과 관계없는 시연 값입니다.

## 직접 사진 사용법

1. 앱을 열면 기본으로 직접 사진 업로드 화면이 표시됩니다.
2. 동물이 화면의 대부분을 차지하도록 자른 기준 사진 1~5장을 올립니다.
3. 보호자가 잘 아는 털 색·얼굴 무늬·귀·체형·꼬리를 등록합니다.
   각 특징 아래에 항상 보이는 직접 입력 칸에 자유롭게 적을 수 있습니다. 내용을 쓰면 선택값보다 우선하며, 여러 털 색은 쉼표로 구분합니다.
4. 마지막 확인 장소와 시각을 입력합니다. 위도·경도는 지도 표시가 필요할 때만 선택 입력합니다.
5. 아직 제보가 없다면 `제보 수`를 0으로 두고, 제보가 들어오면 수를 늘려 사진과 촬영 정보를 기록합니다.
   제보마다 마지막 확인 장소와의 대략 거리와 이동 방향을 적으면 좌표 없이도 이동 가능성과 장소 경로를 계산합니다.
6. 분석 후 사진 원본을 직접 확인하고 경로에 사용할 제보를 선택합니다.

업로드하면 기준 사진과 목격 사진의 미리보기가 즉시 표시됩니다. 자료는 현재 Streamlit 세션에서 분석할 뿐 저장소 파일로 쓰지 않습니다.

직접 입력한 특징은 현재 앱 세션에 임시 보관되므로 제보 수를 줄였다 다시 늘려도 복원됩니다. 앱을 완전히 새로고침하거나 종료하면 개인정보 보호를 위해 사라지며 디스크에는 저장하지 않습니다. 입력값은 앞뒤 공백과 연속 공백을 정리한 뒤 비교합니다. 같은 특징은 보호자와 제보자가 가능한 한 같은 표현으로 적어야 하며, 뜻이 비슷해도 문장이 다르면 자동으로 일치하지 않을 수 있습니다.

## 결과 해석

- **검토 우선도:** 사진 단서, 관찰 특징, 화질 신뢰도, 이동 가능성을 조합해 제보 순서를 정리한 값입니다. 동일 동물일 확률이 아닙니다.
- **단서 유사도:** 사진과 사람이 기록한 특징이 닮은 정도를 0~100%로 표시한 값입니다. 동일 동물일 확률이나 확정 결과가 아닙니다.
- **사진 단서:** 색 분포, 윤곽·질감, 저해상도 시각 패턴의 유사성입니다. 배경과 촬영 각도의 영향을 받습니다.
- **분석 신뢰도:** 선명도·노출·대비와 사용자가 기록한 가시성을 합친 참고값입니다.
- **판단 보류:** 점수가 높아도 사진 선명도가 기준보다 낮거나 동물이 일부만 보이는 경우입니다. 더 가까운 사진 또는 얼굴·귀·꼬리가 보이는 다른 각도 사진을 요청합니다.
- **이동 경로 재확인:** 마지막 위치에서 해당 목격 위치까지 필요한 평균 속도가 사용자가 정한 시나리오 범위를 넘는 경우입니다. 좌표가 없으면 사용자가 입력한 대략 거리를 사용하며 제보를 자동 배제하지 않습니다.
- **예상 수색 범위:** 확인한 장소·시각·대략 거리·방향을 바탕으로 만든 참고값입니다. 도로·지형·동물 행동을 반영한 정확한 위치 예측이 아닙니다.
- **다음 수색 기준 장소:** 보호자가 원본을 확인한 제보 중 촬영 시각이 가장 늦은 장소입니다. 이동 가능성 경고가 있어도 자동 제외하지 않고 촬영 정보 재확인을 함께 안내합니다.

## 한계

- 현재 동물 자동 탐지·분할 모델이 없어 배경이 사진 특징에 영향을 줍니다.
- 귀·꼬리·얼굴 무늬 같은 세부 특징은 사람이 관찰해 선택합니다.
- 좌표 또는 사용자가 입력한 대략 거리를 사용하므로 도로, 하천, 울타리, 건물, 동물 행동을 반영하지 않습니다.
- 좌표 없이 계산한 경로와 수색 범위는 입력한 장소명·이동 방향·대략적인 거리만 사용한 참고값입니다.
- 지도 타일은 인터넷이 없으면 보이지 않을 수 있지만 좌표와 경로 표는 사용할 수 있습니다.
- 실제 구조 활동에서는 지역 보호소·동물병원·관계 기관의 안내와 현장 안전을 우선해야 합니다.

## 자주 생기는 오류

### `No module named streamlit` 또는 `No module named cv2`

가상환경을 활성화한 뒤 다음을 실행합니다.

```powershell
python -m pip install -r requirements.txt
```

### 사진을 읽을 수 없음

손상되지 않은 JPG/JPEG/PNG인지 확인하고, HEIC 사진은 JPG 또는 PNG 사본으로 변환하세요.

### 결과가 배경색을 따라감

첫 시제품은 동물 자동 분할을 하지 않습니다. 동물이 화면의 대부분을 차지하도록 사진을 잘라 다시 올리세요.

### 지도에 아무것도 보이지 않음

인터넷 연결이 없으면 지도 타일이 표시되지 않을 수 있습니다. 화면의 위경도와 경로 표를 대신 사용하세요.
